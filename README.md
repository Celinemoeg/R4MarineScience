## A repo with code and data for Techniques in Marine Science 1 (MB5370) - R for Marine Science

## This repo holds my work for workshop 1: Foundations of Data Science, covering data wrangling and plotting in R using the tidyverse. It includes importing messy marine datasets, exploring the Palmer Penguins dataset, summarising data with `dplyr`, and visualising it with `ggplot2`.
